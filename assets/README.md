# Assets MyWeek

Estrutura de mídia e recursos estáticos.

- **images/** — Imagens (logo, favicon, ilustrações). Use nomes descritivos (ex: `logo-myweek.svg`, `hero-bg-club.jpg`).
- **videos/** — Vídeos (ex: `hero-bokeh.mp4` para o hero).
- **fonts/** — Fontes locais (opcional). O site usa **Google Fonts**: *Outfit* (títulos/logo) e *Inter* (corpo).
- **images/screens/** — Screens do sandbox (app/web) na landpage. Web: área central sem menu/topo. App: tela quase completa. Carrosséis em Timing (filtros), Mapa (org/admin/partner) e Como chegar (app + Maps).
- **svgs/** — Ícones e SVGs reutilizáveis.

Os caminhos no site referenciam `assets/images/`, `assets/videos/`, etc. a partir da raiz do projeto.
